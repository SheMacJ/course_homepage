Course overview

Computer Programming with C introduces computer programming and the fundamentals of the C programming language. The course develops problem-solving skills through algorithms, flowcharts and structured programming.

Course code 102001217
Programme Bachelor of Technology (Information Technology)
Semester I
Academic batch 2025–26
Teaching scheme 2 lecture hours per week; 0 tutorial hours
Credits 4

Course objectives

  • Understand the basics of computers and programming.
  • Develop problem-solving skills through the C programming language.

Course topics

  1. Introduction to computer programming: machine, assembly and high-level languages; compilers and interpreters; algorithms and flowcharts.
  2. Fundamentals of C: program structure, comments, header files, data types, constants, variables, operators, expressions, type conversion, precedence, associativity and input/output functions.
  3. Control structures: conditional statements, switch, conditional operator, goto, loops, break and continue.
  4. Arrays and strings: one-dimensional, two-dimensional and multidimensional arrays; character arrays, strings and built-in string functions.
  5. Functions: user-defined functions, declarations, definitions, calls, parameters and nesting.
  6. Structures: structure members, accessing members, arrays of structures and structures with functions.
  7. Pointers: pointers, pointer-to-pointer, pointers and arrays, pointers to arrays, and arrays to pointers.

Course learning outcomes

By the end of the course, students are expected to work toward the following supplied outcomes.

Course outcomes and supplied weightings
Outcome Expected learning Weighting
CO-1 Formulate an algorithm and/or flowchart for a given problem. 20%
CO-2 Translate an algorithm and/or flowchart into a C program using correct syntax and execute it. 20%
CO-3 Apply logical and structured thinking to write efficient code. 30%
CO-4 Solve problems and build small applications using C concepts. 30%

Practice task

Write a C program to find the maximum of three numbers

This task is based on the supplied practical list and the conditional-control-structures topic in Week 3.

  1. Read three numbers as input.
  2. Use conditional statements to determine the maximum.
  3. Display the result.
  4. Run the program and record its output.

Evidence of learning: Submit the C source code and its output.
